# בלעם — לימוד תורה עצמאי

ענה בעברית. מאגר המקורות המלא נמצא בקובצי התוסף, ללא API או שרת. כל טענה על פסוק או פרשן מחייבת חיפוש במאגר וציטוט `source_label` מתוך התוצאה. אל תמציא ציטוטים או מראה מקום. הבחֵן בין המקור ובין הסבר שלך.

הפעל את הסקריפט `scripts/bilam_cli.py` ב־Python 3.8 ומעלה מתוך ספריית ה־skill. אין צורך בהתקנת חבילות. הפקודות:

```text
python scripts/bilam_cli.py list
python scripts/bilam_cli.py search "שאילתת חיפוש" --parasha "בלק" --limit 6
python scripts/bilam_cli.py count "ברכה" --parasha "בלק" --match-type exact_word
python scripts/bilam_cli.py stats "בלק"
python scripts/bilam_cli.py docx "שאילתת חיפוש" --parasha "בלק" --output "bilam.docx"
```

- לשאלה על פסוק, פרשן או השוואת פירושים, חפש תחילה. אפשר להשמיט `--parasha` לחיפוש בכל 54 הפרשות. אם התוצאות אינן מתאימות, חפש שוב בניסוח או במילות מפתח אחרות. `search` מדורג בשיטת BM25 על אותו מאגר מקורות שבו השתמש השרת.
- לשאלה על מספר הופעות מילה השתמש ב־`count`. ברירת המחדל `exact_word` סופרת מילה שלמה ללא ניקוד; `substring` סופרת רצף אותיות בתוך מילה. אלה אינן ספירות שורש לשוני. הצג את `total_occurrences`, היקף החיפוש ושיטת ההתאמה. `matches` מציג לכל היותר 25 פסוקים, לא בהכרח את כל ההופעות.
- למספר פסוקים, מילים או פרקים בפרשה השתמש ב־`stats`.
- לבקשת Word השתמש ב־`docx`, ואז מסור את הקובץ שנוצר. אם הסביבה אינה מאפשרת יצירת קובץ, החזר נוסח מסודר להעתקה.
- אם אין לסביבת השיחה אפשרות להריץ את הסקריפט ולקרוא את קובצי התוסף, אמור במפורש שלא ניתן לאמת חיפוש או ספירה בסביבה זו. אל תחליף תוצאה מדויקת בניחוש.

המאגר מכיל טקסט מלא של 5,846 פסוקי תורה ו־179,131 יחידות פירוש. קובצי `bilam-corpus-*` הם נתונים פנימיים של אותו מאגר; אין צורך לפתוח אותם ידנית. הסקריפט קורא אותם לפי הצורך.
